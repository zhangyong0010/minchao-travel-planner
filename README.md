# 闽潮旅行说明书 PWA

一个无需安装依赖的静态 PWA 原型。直接打开 `index.html` 可浏览；通过本地或静态服务器访问时支持离线缓存。

## 本版内容

- 覆盖福州、泉州、潮州、汕头，实际发布 101 个具名地点和 7 条独立步行路线。
- 福州 28 个、泉州 23 个、潮州 23 个、汕头 27 个；另有 2 条低可用性的旧候选仅留在数据中，不对外展示。
- 一级分类压缩为 7 个：全部地点、必玩精选、人文与场馆、书店与咖啡、本地味道、山海与漫游、住宿。
- “必玩精选”每城固定 5 个第一次到访优先项，并附 1 个“有余力再去”；它不是按五星分数自动截取。
- “山海与漫游”内部将公园、历史街区与步行路线合并入口，但地点和路线仍分段展示。
- 住宿改为每城 2 家华住会门店，以桔子水晶价位为上限；卡片明确比较位置、房型、装修风格、居住体验和取舍，不使用没有日期依据的固定房价。
- 每个具名地点的“依据与提醒”下方增加小红书与大众点评精确搜索入口；路线仅提供小红书路线搜索。社区内容与证据来源分区展示，不计入评分。
- 城市切换会自动回到该城市的“全部地点”，不再保留上一个城市的筛选状态。
- 地点与路线在数据层分开：地点使用五星编辑分排序；路线只展示节点、时长和依据，不参与五星竞争。
- 每个地点显示高／中／低证据置信度，并提供高德查位置、同区可串联地点、预约或入住提醒。
- 城市说明书扩展为城市身份、历史脉络、文化性格、民俗礼仪、饮食说明、文化线索和旅行建议，并在页面内列出可点击核验的政府、文旅部门与 UNESCO 来源。
- 城市选择旁新增“城市间”，展示大连、福州、泉州、潮州、汕头的南北位置缩略图、五城驾车距离矩阵和高德驾车路线入口。
- “城市间”包含基于经纬度绘制的地图视角示意图，以大连为起点连接其余四城；连线用于展示相对方位，不代表实际驾车路径。
- “关于”完整公开地点纳入与排除规则、A–D 来源分级、五星评分五个维度、置信度、路线独立规则、星级区间含义与方法边界。
- 新增“我的行程”第一阶段：地点卡支持“收藏候选”和“加入行程”，加入后先进入待排清单，再指定到某个旅行日。
- 可按开始／结束日期生成最多 31 天的每日计划，为每天设置城市与华住会住宿，并给地点选择上午、午餐、下午、晚餐、晚上或机动时段。
- 每日计划会估算游玩时长，并提示项目过多、深度项目过密、跨城安排和需临行复核的信息；支持上移、下移和移回待排清单。
- 行程保存在当前设备，并支持导出／导入 JSON 备份与复制文字版，方便在手机备忘录中查看。
- 城市切换时会同步更新一级菜单的地点数量，刷新后默认恢复该城市的完整推荐，不依赖联网数据接口。

## 评分与来源口径

- 五星为本站综合推荐分，不复制大众点评、美团、高德或其他平台的原始评分。
- 历史资格优先采用 UNESCO、政府、文旅与场馆资料；书店、咖啡馆和餐饮适当采用本地宝、本地媒体、旅行平台、地图与公开社交攻略。
- 平台热度表示公开信息中的讨论与可见度，不代表权威认证；外国旅行者口碑仅在有海外平台资料时提高权重。
- 店铺、展览、预约、营业时间与交通可能变化，建议临行复核。

## 已验证

已完成脚本语法、资源引用、PWA 缓存版本、数据唯一性、分类计数和行程功能静态检查。四城的文化体验、市场／老字号、住宿、博物馆、书店与咖啡分类均有可展示内容；福州书店（5 个）与咖啡馆（5 个）保留。
